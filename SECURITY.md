# Security and Privacy Notice

This repository documents an authorized personal cloud-security lab.

- Do not submit real credentials, access tokens, private keys, or unredacted cloud identifiers through issues or pull requests.
- IP addresses, subscription IDs, tenant IDs, and email addresses shown in evidence should remain redacted.
- Findings are educational and point-in-time; they should not be interpreted as an assurance opinion or certification.
- If sensitive information is discovered in the repository, contact the repository owner privately rather than opening a public issue.
